# 지미니의 감정 수업

6학년 도덕(인공지능 윤리) 2차시 수업용 웹 게임입니다. 학생은 피노키오에게 감정을 가르치는 보조 프로그램 '지미니'가 되어 다섯 장면에서 선택하고, 네 가지 엔딩 가운데 하나에 이릅니다.

- 바탕 교재: 박형빈(2025), 『질문으로 답을 찾는 인공지능 윤리 수업』, 한언, 에피소드6(87~97쪽). 대사 옆 쪽수 표시는 교재 문장을 옮긴 줄입니다.
- 그림: 생성형 AI(Gemini)로 만든 이미지, 지미니 아이콘은 직접 그림
